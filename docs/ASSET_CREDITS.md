# Asset notes

## Concept illustrations

| Original | Role |
| --- | --- |
| `dist/assets/prosthesis.png` | Conceptual hand-prosthesis illustration used by the page and slides. |
| `dist/assets/workshop.png` | Imagined prototyping workshop used by the page and slides. |

Both originals were supplied with the project and are identified in its content as AI-generated. The generation service/model, prompt, creator, generation date, and reuse terms were not supplied. These details should be recorded by the project owner when available.

`*-640.webp`, `*-1024.webp`, and `*-1536.webp` are resized, compressed derivatives of those originals, generated with `scripts/optimize_images.py` using Pillow 13.0.0, WebP quality 82, and method 6. The original PNGs are retained as editable masters and browser fallbacks. Conversion does not change the illustrations' underlying reuse terms.

| Illustration | Original PNG | Full-size WebP |
| --- | ---: | ---: |
| Prosthesis | 1,843,448 bytes | 62,470 bytes |
| Workshop | 2,305,638 bytes | 171,050 bytes |
| **Combined** | **4,149,086 bytes** | **233,520 bytes** |

The full-size pair is **94.4% smaller**. Actual requests depend on screen size, pixel density, browser format support, and caching.

## Logo and favicon
